### 🖥️ Profile
`Bot Customizer & Script Developer`

An independent developer focused on customizing and enhancing chat bots and automation workflows. I specialize in modifying existing codebases for Discord and Telegram platforms, leveraging modern tools and AI assistance to build functional features.

---

### 🛠️ Core Capabilities

* **Bot Customization (Discord & Telegram):** Modifying and expanding bot scripts (using libraries like Discord.js or Telegraf) to add custom commands, utility tools, and group automation.
* **AI-Assisted Development:** Efficiently refactoring code, debugging script errors, and implementing new features using AI workflows.
* **Scripting & API Integration:** Connecting bot events with external APIs, webhooks, and basic server-side tools.

---

### 📦 Areas of Focus

* **Discord Bot Enhancements:** Adding custom systems, management tools, and interactive features to existing bot scripts.
* **Telegram Automation:** Customizing event-driven scripts for channel/group management and automated notification delivery.
* **Lightweight Scripting:** Writing and adapting backend scripts using Node.js and TypeScript to keep automations stable.
